# روژ — برنامه‌ریز روزانه PWA

یک برنامه‌ریز فارسی، مینیمال و آفلاین با تقویم شمسی، یادداشت و عکس، چک‌لیست، مناسبت‌ها و حالت تاریک.

## اجرا
PWA و Service Worker روی `file://` فعال نمی‌شوند؛ پروژه را از طریق یک وب‌سرور محلی یا میزبانی HTTPS اجرا کنید.

مثلاً با Python:
```bash
python -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید.

## قابلیت‌ها
- یادداشت جداگانه برای هر روز با IndexedDB
- افزودن چند تصویر به یادداشت‌ها
- علامت‌گذاری انجام‌شده، ویرایش و حذف
- فهرست تمام کارهای انجام‌نشده
- تقویم شمسی و فهرست مناسبت‌های ثابت محلی
- تم روشن و تاریک ذخیره‌شونده
- کش فایل‌های اصلی برای استفاده آفلاین پس از بازدید اولیه

## نکته درباره مناسبت‌ها
مناسبت‌های ثابت و برخی مناسبت‌های جهانی در داده محلی برنامه گنجانده شده‌اند. تاریخ‌های قمری و تعطیلات متغیر رسمی، برای نمایش قطعی باید با تقویم رسمی همان سال به‌روزرسانی شوند؛ برنامه عمداً تاریخ قمری نامطمئن را حدس نمی‌زند.

## حریم داده
یادداشت‌ها و تصاویر در IndexedDB مرورگر همین دستگاه ذخیره می‌شوند. پاک کردن داده‌های سایت/مرورگر ممکن است آن‌ها را حذف کند. نسخه فعلی قابلیت خروجی/بازیابی پشتیبان ندارد.
